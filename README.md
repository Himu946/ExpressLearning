# 🚂 Express Learning

A small Node.js + Express app I built while learning server-side JavaScript. It serves an HTML form and handles the form submission on the server.

## What it covers

- Setting up an Express server
- `GET` and `POST` routes
- Parsing form data with `body-parser`
- Auto-restarting during development with `nodemon`

## Run it locally

```bash
git clone https://github.com/Himu946/ExpressLearning.git
cd ExpressLearning
npm install
npm start
```

Then open the `/add-product` route in your browser (see `app.js` for the port).

## Tech stack

Node.js · Express · body-parser · nodemon
